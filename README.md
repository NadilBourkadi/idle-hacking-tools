# idle-hacking-tools

Research, strategy and tooling workspace for the browser game [Idle Hacking](https://www.idlehacking.com/), migrated from a ChatGPT Project on 2026-07-22 (raw handover preserved in the initial commit).

- `CLAUDE.md` — operating guide: source-of-truth order, analysis rules, guardrails, conventions.
- `docs/` — maintained game knowledge, decision records and open questions.
- `data/` — structured save-state exports and combat logs captured by the userscript.
- `tools/item-loadout-capture.user.js` — passive Tampermonkey capture script (read-only by design; it never performs gameplay actions).
